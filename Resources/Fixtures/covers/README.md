# Original GenBooks artwork

All app-icon and cover PNGs are deterministic renderings of the original geometric paths in `scripts/generate_brand_assets.swift`. The generator uses no input images, external fonts, or third-party marks. These assets and their source are included under this project's MIT license.

Run `swift scripts/generate_brand_assets.swift` from the repository root on macOS to reproduce them. Catalog names and fixture filenames remain stable so previously saved books can use the new artwork without changing manuscript data. `CoverQuran` is a generic geometric book cover; it does not include translation content.
